# Repeat / Speaking（リピスラ）

Marks Tools の英語スピーキング練習アプリです。Magical / Reading（マジスラ）の姉妹アプリとして、
日本語のお題を見て、英語のチャンク（意味の塊）を前から組み立てて話す練習をします。

- バージョン: 0.1.0（Phase 1 最小試作版）
- 仕様: 詳細実装仕様書 v1.1 に準拠
- 方式: HTML / CSS / JavaScript、GitHub Pages での公開を前提

## Phase 1 でできること

- ホームから「今日の10問」を開始し、10問連続で練習できます。
- 日本語のお題と場面だけが表示され、英語のお手本は最初は出ません。
- マイクボタンで音声認識（Web Speech API）を使い、英語で回答します。
  対応していないブラウザではテキスト入力に切り替わります。
- 回答は登録済みの許容回答と照合し、「正解」または「未判定」で表示します。
  模範解答と違うだけでは不正解にしません。未判定は不正解として記録しません。
- お手本は通常表示とチャンク表示を切り替えでき、チャンクを押すと日本語訳が見られます。
- お手本の音声再生（全体）と、チャンク単位の再生ができます。
- ヒントは3段階（英文の骨格 → チャンクの骨格 → お手本）で、使用したことが記録に残ります。
- 同じ問題を「もう一度話す」で再練習できます。再発話は初回回答と区別して記録され、
  初回の成績は上書きされません。
- 10問終わるとセット結果（初回回答の正解数・未判定数）が表示されます。
- 学習記録は端末内の IndexedDB に保存され、学習記録画面で直近の回答を確認できます。
- 設定画面で問題数・難易度・回答方法・ヒント・お手本再生・正解後の進行・音声言語（en-US / en-GB）を
  変更できます。バージョン表示と「最新版を読み込む」ボタンも設定画面にあります。

## まだ実装していないこと（Phase 2 / 3）

- 型の練習・時制の練習・動詞の練習・シャッフル・苦手を復習の各モード（ホームで「実装予定」と表示）
- 問題集100問化（現在は Phase 1 用の10問）
- 習熟度4段階の管理と分野別集計
- 外部AI相談の画面（質問文の生成部品のみ用意済み）
- 自分の回答を正解として登録する機能
- JSON の書き出し / 読み込み
- クラウド同期（初版では行いません）

## 判定の考え方

比較の前に、大文字小文字・文末の句読点・余分な空白・明確に対応する短縮形（I've = I have など）を
そろえてから、登録済みの許容回答と照合します。文字列の類似度だけで正誤は決めません。
音声認識に失敗した場合は、発音の問題とはせず、再発話かテキスト入力を案内します。

## ファイル構成

```
repeat-speaking/
├── index.html
├── style.css
├── README.md
├── js/
│   ├── app.js         初期化と状態管理
│   ├── screens.js     画面表示と遷移
│   ├── questions.js   問題データの読み込み
│   ├── speech.js      音声認識と音声合成
│   ├── evaluator.js   正規化と照合
│   ├── learning.js    出題順序と集計
│   ├── storage.js     IndexedDB 保存
│   └── ai-consult.js  外部AI相談の質問文生成（Phase 3 で画面に接続）
├── data/
│   └── questions.json 問題データ（本体と分離）
└── assets/icons/
```

問題データ（data/questions.json）が読み込めない環境向けに、js/questions.js 内に
同一内容の退避コピーを持っています。問題を直すときは questions.json を正としてください。

## 動作確認について

判定ロジックと問題データの整合性は自動テストで確認済みです（T01〜T04 相当を含む）。
iPhone Safari での実機確認（マイク許可・音声認識・連続10問・画面ロック後の復帰など）は
まだ行っていません。実機での確認結果を受けて、次版で調整します。
